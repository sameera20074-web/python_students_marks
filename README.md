# NumPy Student Marks Analysis

## Description
This project creates a NumPy array containing student marks and calculates mean, median, maximum, minimum, and standard deviation.

## Objective
Learn how NumPy can efficiently perform numerical analysis.

## Tools Used
- Python
- NumPy
- Jupyter Notebook

## Code
```python
import numpy as np
marks = np.array([85, 92, 78, 88, 76, 95, 89, 72, 84, 91])
print("Mean:", np.mean(marks))
print("Median:", np.median(marks))
print("Max:", np.max(marks))
print("Min:", np.min(marks))
print("Std Dev:", np.std(marks))
